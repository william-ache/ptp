# Reglas de Diseño Frontend
- Usa siempre Tailwind CSS vía CDN para estilos rápidos y limpios.
- Prioriza tipografías modernas de Google Fonts (como Plus Jakarta Sans o Inter).
- Añade jerarquía visual clara, contrastes altos, sombras suaves y estados hover en todos los botones y tarjetas.
- Evita diseños genéricos: usa gradientes sutiles, espaciado generoso (padding/margin) y estructura modular.
